# Privacy Policy

**Last updated:** March 12, 2026

## Emfit WiFi Setup

Emfit WiFi Setup is an application used to configure WiFi connectivity for Emfit devices. The application scans the device QR code, connects the phone to the device’s temporary setup network, and transfers the selected WiFi network credentials to the device.

The application is designed solely for device provisioning and operates primarily through a local connection between the phone and the device being configured.

## Information the Application Processes

The application may process the following information during device setup:

- Device QR code contents, such as the device serial number and device password
- Selected WiFi network name (SSID)
- Selected WiFi network password
- Names of nearby WiFi networks detected by the phone when the user opens the list of available networks

## How the Information Is Used

The information is used only for the following purposes:

- Scanning the device QR code
- Identifying the correct device
- Connecting the phone to the device setup network
- Sending the selected WiFi network credentials to the device
- Completing the device setup process

## User Data Collection

The application does **not collect, sell, transmit, or share personal user data** with Emfit servers or third-party services.

The application does **not include analytics frameworks, advertising SDKs, tracking technologies, or user profiling mechanisms**.

All provisioning-related information is handled locally on the user's device and through the direct local network connection between the phone and the device.

## Data Sharing

The application does not transmit QR code information, WiFi network names, or WiFi passwords to external servers.

During device setup, the phone sends the selected WiFi credentials directly to the device being configured using the device’s temporary local setup network.

## Local Data Storage

The application may store the selected WiFi network name and password locally on the phone to simplify the setup of additional devices.

This information is stored using the device's local secure storage mechanisms and is not transmitted outside the device.

## Permissions

The application may request the following permissions:

- **Camera** – required for scanning the device QR code
- **Location** – required by Android to display nearby WiFi networks
- **WiFi and Network Access** – required to connect to the device setup network and complete configuration

On Android devices, location-related permissions may be required by the operating system to display nearby WiFi networks even though the application does **not use, track, or store the user's physical location**.

## Third-Party Services

The application does **not use third-party analytics services, advertising networks, or external data collection services**.

All functionality operates locally on the device and through a direct local network connection with the device being configured.

## Data Retention

Locally stored WiFi credentials remain on the phone until the user removes them from the application or uninstalls the application.

## Security

The application is designed to handle only the minimal information required for device setup. Data is processed primarily locally on the device and transmitted only through the temporary setup network created by the device.

## Changes to This Privacy Policy

This Privacy Policy may be updated if the functionality of the application changes. When updates occur, the revised policy will be published with an updated **"Last updated"** date.
